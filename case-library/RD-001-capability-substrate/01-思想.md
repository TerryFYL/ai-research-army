# 01 · 思想精华（可迁移的道理）

> 全文权威版见 `docs/architecture/00-charter.md`；这里只留**能搬到别的项目去用**的内核。

## 1. 自底向上的主角是"分化"，不只是"组合"
- **是什么**：底层能力 + 附加条件 → 派生出一窝专门能力（一生多）；专门能力再聚合成功能单元（多合一）。
- **为什么重要**：只维护少数"干细胞"+ 一套加条件规则，绝大多数能力是*派生*的；底层一升级，整条谱系自动继承。
- **迁移到哪**：任何"从原子能力往上搭"的系统。别想着手写每一个原子——想"干细胞 + 分化算子"。

## 2. 统一类型 → 递归自相似生长
- **是什么**：干细胞、专门细胞、组合器官**是同一个类型**，所以器官能被当成新干细胞继续分化/组合。
- **为什么重要**：这是"越搭越高"在结构上能成立的根；不统一类型，层与层之间就要写胶水、长不上去。
- **迁移到哪**：插件/能力/agent 体系的类型设计——让"组合的结果"和"被组合的零件"同型。

## 3. 大模型是"预训练好的皮层"，要建的是身体，不是大脑
- **是什么**：不必从零进化出智能；把大模型当一颗高能干细胞接进去，建神经/免疫/循环/可塑性这些**身体脚手架**。
- **为什么重要**：省掉"长出皮层"那几十亿年，把工程量放在组织方式上，而不是智能本身。
- **迁移到哪**：所有 LLM 应用——你的增量价值在"身体"(编排/质检/记忆/进化)，不在重造大脑。

## 4. 通用性是涌现的，是"量"的相变
- **是什么**：当分化/组合成为神经系统的*运行时操作*、且**连通的**能力跨过临界质量，复杂任务**突然**可达。
- **为什么重要**：解释了"量小做不起来、量够才行"。复杂能力不是攒出来的，是相变出来的（类比自催化集/渗流/LLM 涌现）。
- **两道阈值**：广度（多样性+连通）决定通路*是否存在*；可靠度（每步成功率）决定深通路*能否跑成*——必须同步长。
- **迁移到哪**：评估一个能力系统"还差多少能做难任务"——看可达任务空间、看离临界还差哪几个**连接子**，而非数任务。

## 5. 朴素的科学循环驱动一切（OODA = 科学方法）
- **是什么**：可测目标 → 假设(预设判据) → 最小实验 → 数据验证(主动证伪) → 决策；直到差距≈0。
- **为什么重要**：朴素的是结构，科学性来自**纪律**（可测目标 / 判据先写死并证伪 / 最小实验+账本），不来自复杂度。
- **迁移到哪**：任何"自动迭代逼近目标"的 agent loop。三道纪律是 naive 循环和科学循环的分界。

## 6. "完成"必须有可客观验证的定义，且标准是个函数
- **是什么**：完成定义 = `f(目标, 类型)` 编出的**审核清单**；分"合格(硬闸门全过)"与"高质量(评分达阈)"两层。
- **为什么重要**：流程跑完 ≠ 完成。没有客观验证器，循环会收敛到"看起来完成"。清单就是循环第 4 步的验证器。
- **迁移到哪**：任何有交付质量要求的自动化——先把"done"写成可机检的清单，再谈自动化。

## 7. 红线：宁可上报，绝不伪造
- **是什么**：做不到的（缺 DOI、需外部核对）明确 escalate，**绝不编造**；验证从数据客观量出，不让模型自判。
- **为什么重要**：自动化循环最大的失败模式是自欺。一条"不可伪造"红线，是可信度的地基（医学场景尤甚）。
- **迁移到哪**：所有自动产出 + 自动验收的系统。把"不可伪造"写进循环的硬约束，而非寄望模型自觉。
