# 03 · 机制清单（可复用的机制与代码）

> 全部离线、无第三方依赖、确定性可复现。入口均为 `python3 -m <module>`（在仓库根运行）。

## 1. 两个算子 + 统一类型 + 谱系
- **作用**：`differentiate(base,+条件)` 一生多；`compose(members,wiring)` 多合一；三类细胞同型 `Capability`，可递归。
- **入口**：`kernel/core.py`；演示 `python3 -m kernel.demo`。
- **复用点**：任何"能力可派生 + 可组合"的体系底座；`Registry` 记谱系，天然可追溯/可回滚。

## 2. 神经系统：按契约运行时自动装配
- **作用**：每个能力声明 `consumes/produces`（受体/配体）；`Orchestrator` 给一个目标，反向推理**现场装配**通路——零预写管线。
- **入口**：`kernel/orchestrator.py`；`kernel.demo` 第二幕（同一池细胞，三个目标→三条不同通路）。
- **复用点**：把"分化/组合"从设计期算子变成运行时操作——这是通用性涌现的开关。契约匹配是关键。

## 3. 临界质量相变实验
- **作用**：在细胞依赖图上量"可达任务数随细胞数"的相变（乱长 16 细胞复杂目标仍为 0，连接子一到级联点亮）。
- **入口**：`kernel/emergence.py`。
- **复用点**：度量一个能力系统离"能做难任务"还差多少；指导**沿依赖闭包定向生长**、优先补连接子。

## 4. 科学循环 / OODA 自修订闭环
- **作用**：Observe(审核)→Orient(选一条红)→Decide(最小修订+预设判据)→Act(改)，过**三道闸**（证伪复验/单调不回退/记账）；驱动稿件单调收敛。
- **入口**：`kernel/scientific_loop.py`。
- **复用点**：任何"自动迭代逼近目标"的闭环模板；三道闸防自欺；ESCALATE 路径守红线（不可伪造）。

## 5. 标准驱动的客观审核器
- **作用**：读 `standards/<刊>.yaml`（29 硬闸门 + 质量分），对稿件跑 pass/fail 探针，出红/黄/绿报告 + 合格判定。
- **入口**：`validators/manuscript_audit.py`；标准 `standards/nature-cohort.yaml`。
- **复用点**：把"完成定义"做成**数据驱动、可机检、有出处**的验证器；做不到的标 NEEDS-REVIEW 不伪绿。

## 6. 可插拔后端模式（Mock ↔ 真实，即插即用）
- **作用**：`StubLLM`（离线确定性）与 `AnthropicLLM`（真实）**接口一致**；有 Key 直接换，结构不改。
- **入口**：`kernel/backends.py`。
- **复用点**：先用 Mock 把整套结构闭环跑通，真实后端最后接——降风险、可离线开发。

## 机制之间怎么串
```
core(算子) → orchestrator(按契约装配产出稿件) → scientific_loop(audit→revise 收敛)
                                                      ↑
                              manuscript_audit + standards/*.yaml(客观验证器)
backends(StubLLM↔AnthropicLLM 即插即用) 贯穿其中；emergence 用于度量与定向生长决策
```
