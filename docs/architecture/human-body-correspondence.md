# 人体参照蓝图：AI 能力体系的同构映射

> 目标：把人体这套"从细胞涌现出智慧"的组织方式当作参考蓝图，
> 找到 AI 构件（大模型、工具、存储…）与人体各层级/子系统的对应关系，
> 然后照人体已被验证的组织逻辑去构建。
>
> 本文是 [`capability-substrate.md`](./capability-substrate.md) 的立意升级版：
> 前者给"分化/组合"两个算子，本文给"整套人体到底对应什么、该照着建什么"。

---

## 1. 纵向同构：层级对应（结构）

| 人体层级 | 本质角色 | AI 对应 | 现状 |
|---------|---------|---------|------|
| **基因组 DNA** | 蓝图。每个细胞携带同一份，决定"能分化成什么" | **大模型权重 + 契约规范(schema)**。每个能力体共享同一个底模 + 同一套接口约定 | 已有底模；契约部分实现 |
| **分子 / 化学反应** | 执行一次具体反应的机器 | **单次 LLM 推理 / 单次工具调用**。一次"反应"，本身不自持 | 已有 |
| **细胞器** | 细胞内的功能部件 | 能力体**内部子步骤**：prompt 模板、输出解析器、schema 校验 | 已有 |
| **干细胞** | 未特化、可分化的基本生命单元 | **干细胞能力**：语言/计算/存取/检索/通信 | ✅ `kernel` |
| **分化信号(激素/形态发生素)** | 让干细胞特化的环境条件 | **`differentiate` 注入的条件**(task/instruction/fn) | ✅ `kernel` |
| **体细胞(分化后)** | 专门细胞 | **分化能力**：抽取基线、组间比较… | ✅ `kernel` |
| **组织** | 同类细胞聚集 | 同类能力的**家族/集合** | 概念 |
| **器官** | 多组织协作完成一项功能 | **`compose` 出的器官**：一条完整 skill 流程 | ✅ `kernel` + 现有 29 skills |
| **器官系统** | 多器官协同 | **子系统**：数据系统 / 分析系统 / 写作系统 | 概念 |
| **个体 / 心智** | 涌现的智慧 | **顶层编排涌现的"完成复杂科研任务"的能力** | 目标 |

> 关键判断：**AI 这边的"细胞"应该是 `Capability`，而不是一次 LLM API 调用。**
> 细胞是生命里最小的*自持、可复制、可组合*单元，不是最小的零件。
> 一次 API 调用更像一次*化学反应*——能干活，但不自持、不可组合。
> 这正反过来证明了 `kernel` 把 `Capability` 设为统一原子是对的。

## 2. 横切子系统：让结构活起来（机制）

光有层级是一具尸体。智慧不在任何一个神经元里，**它从连接、反馈、可塑性中涌现**。
所以真正要照着建的，是下面这几套"横切全身"的子系统：

| 人体子系统 | 干什么 | AI 对应 | 现状 |
|-----------|-------|---------|------|
| **神经系统** | 快速信号传导 + 全局协调 + 学习 | **编排器 + 消息总线 + 谱系图**（控制流：谁调谁、信息怎么流） | ⚠️ 最缺 |
| **内分泌系统** | 慢速全局调节 | **全局策略**：模型分层路由、质量阈值、预算策略 | 部分(原则4) |
| **免疫系统** | 识别异常 + 防御 + 质检 | **质量审查 / 红队**(Alex/Devil) + 约束门 + 验证细胞 | 已有(skills) |
| **循环 / 代谢** | 能量与物料运输 | **token/算力预算 + 数据/产物的存取与流转**(R2/D1/总线) | 部分 |
| **基因表达 / 表观遗传** | 同一份 DNA，不同条件表达不同 | **同一干细胞 + 不同条件 → 不同能力** | ✅ 已实现 |
| **神经可塑性 / 进化** | 经验改变连接 | **`evolution.md` 的谱系结构手术 + AAR** | 机制已设计 |

## 3. 类比在哪成立、在哪会骗你（不照搬生物学）

照蓝图建，但要知道蓝图的比例尺。三个关键差异决定了我们**不能**逐项复刻人体：

1. **细胞便宜，API 昂贵。**
   人体靠*几十万亿个*慢而廉价的细胞堆出涌现；我们的"细胞"(LLM 调用)又贵又慢又无状态。
   → 我们的涌现**不能靠堆数量**，得靠*聪明的连接 + 反馈回路*。神经系统比细胞数量重要得多。

2. **人体没有设计者，我们有。**
   生物是几十亿年无监督自组织出来的；我们手里有你(设计者) + 一个**预训练好的"基因组/皮层"**(大模型)。
   → 不必从零长出一个大脑。**大模型本身就是一个已经长好的"超级细胞"**，里面已经装了大量智慧，
   我们把它当成一个高能干细胞接进去，省掉"进化出皮层"那几十亿年。

3. **所以建法是"倒装"的。**
   人体：分子→细胞→……→大脑(智慧最后涌现)。
   我们：智慧(大模型)*一开始就在手里*，缺的是**把这颗大脑接进一具能自我维持、自我修复、自我进化的"身体"**——
   即神经系统(协调)、免疫系统(质检)、循环系统(供给)、表观遗传(条件分化)、可塑性(进化)。
   **身体的脚手架才是要建的，不是大脑。**

## 4. 结论：要让智慧涌现，先建"神经系统"

你已经有 29 个器官(skills) 和 10 个人格化视角(agents)——**器官不缺，缺的是把器官连成活体的神经系统**。
按人体蓝图，涌现的高杠杆顺序是：

1. **神经系统（最高优先）** = 统一的**控制/通信底座** + **谱系图**。
   让任意能力体能被发现、被调用、被编排，信息按契约流动。`kernel` 的 Registry + Context 是它的胚胎。
2. **表观遗传** = 条件分化机制。✅ 已实现，是体系能自我扩张的根。
3. **免疫系统** = 把现有的质量审查/约束门接成"每个器官输出都过检"的常驻机制。
4. **可塑性 / 进化** = 把 `evolution.md` 落成"对谱系图动结构手术"的闭环。
5. **循环系统** = 预算 + 存储流转（token 计量、D1/R2 物料流）。

> 一句话：**别再加器官了，先长神经。** 智慧是连接的涌现，不是器官的堆叠。
