# 0→1 发育程序：从裸 API 到通用体系

> 本文回答的不是"一个任务怎么完成"，而是"**这具身体怎么从一颗受精卵长出来**，
> 以及它凭什么能做*各种各样*的任务而不是一条流水线"。
>
> 看的是**能力边界一格格往外推**：每个阶段解锁"这之前不可能、这之后可能"的一类任务。
> 关键质变在 Stage 5 —— 通用性涌现的那一刻。`kernel` 已把 Stage 1–5 跑通。

## 那个质变到底发生在哪：Stage 4 → 5

这是整件事的命门，也是你之前"没看到的效果"：

- **Stage 4 及以前**，"分化"和"组合"是**我（设计者）在设计期**手工执行的动作。
  结果是几条**预写好的管线**——像反射，刺激来了走固定回路。会的任务 = 我接过的任务。
- **Stage 5**，"分化"和"组合"变成**神经系统在运行时**自己执行的动作。
  给一个目标，它在能力池里按契约反向推理，**现场装配**出通路。
  会的任务 ≠ 我接过的任务，而是 = **能力池能拼出来的一切**。

> 这就是"几条流水线" 跨到 "一套能应付各种任务的体系"。
> 通用性不是被*写进去*的，是从"细胞池 + 两个算子 + 一个会用算子的神经系统"里**涌现**出来的。

### 已跑通的实证（`python3 -m kernel.demo` 第二幕）

同一池 6 个细胞，喂三个不同目标，神经系统自动装配出三条不同通路、零预写管线：

```
目标 baseline          → extract_baseline
目标 interpretation    → load_cohort → group_compare → interpret      （自己判断出不需要抽取细胞）
目标 clinical_summary  → 抽取 + 抽取 + 载入 + 比较 + 解读 + 小结      （自己拼出全链路）
```

能力边界从"我写的那一条"扩成了"这池细胞能拼出的全部组合"。**再往池子里加一个细胞，
可达任务的数量是组合式增长的**——这就是从 0 到 1 之后，1 到 N 自动发生的原因。

## 我们现在站在哪 / 接下来怎么长

- **已长出**：Stage 1–4 完整，Stage 5 有**可运行胚胎**（编排器能按契约自动装配）。
- **下一步把 Stage 5 胚胎养成器官系统**，三件事：
  1. **契约升级**：现在用 `consumes/produces` 的键名匹配；升级成带类型/schema 的契约，装配更可靠。
  2. **歧义决断**：一个目标有多条可达通路时，让神经系统按"任务四维特征 + 成本"择优（接 LLM 规划 or 评分）。
  3. **接真后端 + 接 Stage 6 免疫**：把离线 StubLLM 换成真模型，给每个器官出口挂质检细胞。
- **再叠 Stage 7 可塑性**：把跑成功的装配通路固化进谱系（对接 `evolution.md` 的结构手术），实现"越用越强"。

> 北极星任务（曙光心衰→投稿初稿）不再是"要完成的那个任务"，
> 而是 **Stage 5→7 这具神经系统长成时，顺手就能装配出来的第一条复杂通路**。
> 体系先于任务——这正是你要的"搭体系，不是完成任务"。
