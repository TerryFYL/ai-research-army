> 它有三重身份：① 检验架构的用例；② P1 的验收测试；③ 神经系统的第一条"反射弧"。
>
> 配套：[`human-body-correspondence.md`](./human-body-correspondence.md)（蓝图）、

## 1. 场景设定（真实、可替换为实际数据）

- **客户**：某三甲医院心内科研究生，手里一批曙光医院 HFpEF（射血分数保留型心衰）回顾性住院队列。
- **数据**：一个 Excel，约 800 例，含人口学 / 合并症 / 实验室 / 超声 / 用药 / 随访结局（再入院、全因死亡、随访时长）。
- **诉求**（原话，模糊）："帮我把这批数据做成一篇能投 *ESC Heart Failure* 的回顾性队列研究初稿，三周内。"
- **交付物**：`research_plan` + Table 1 + 主分析（Cox/Logistic + KM）+ IMRAD 初稿 + 投稿包。
- **约束**（医学零容错）：统计结果必须真算、引文必须跨库验证、方法有疑虑选保守方案。

> 真实跑通时，把上面换成实际数据字典即可——剧本结构不变。

## 2. 全栈执行剧本（一条反射弧，逐层流过身体）

下面是这条任务在体内流动的全过程。每步标注：**【人体部件】**、调用的能力、**现状**（✅有 / ⚠️缺）。

### 输入 → 感觉神经
1. **【感觉输入】** 客户原话 + Excel 进入系统。
   `io·通信细胞`（Gmail/Drive 取件）⚠️缺接入
2. **【脊髓初判】神经系统**把任务路由到主通路，并按"四维任务特征"（复杂/零容错/3周/中成本）定档。
   `编排细胞`（控制流）⚠️**最缺——这是 P1 核心**

### 处理 → 各器官系统依次激活
3. **【需求结晶 · 前额叶】** 把模糊诉求结晶成结构化研究问题（PICOT + 主/次结局 + 期刊层级）。
   器官 `research-design`（Priya/Kenji 视角）✅有
   - 分化用到的细胞：`llm·语言细胞`+条件{结晶访谈}、`fetch·检索细胞`+条件{期刊画像}
4. **【数据系统 · 消化吸收】** 数据画像 → 取证鉴伪 → 清洗标准化，产出 `data_dictionary` + `data_clean`。
   器官 `data-profiler` → `data-forensics`（Ming/Alex）✅有
   - 细胞：`compute·计算细胞`+条件{缺失率/异常值/逻辑校验}、`store·存取细胞`+条件{落 R2}
5. **【分析系统 · 心脏泵血】** 假设声明 → 前提检验 → 主分析（Cox 比例风险，含 Schoenfeld 检验）→ 亚组 + 敏感性 → Table 1。
   器官 `stat-analysis`（Kenji）✅有（kernel 已能跑通其原子版：组间比较真算 Mann-Whitney）
   - 细胞：`compute`+条件{normality}、{cox_ph}、{km}、`llm`+条件{假设生成}
6. **【可视化 · 表达】** 生成投稿级 KM 曲线 + 森林图，并与统计结果**对账**（数字一致性）。
   器官 `academic-figure`（Lena）✅有
7. **【文献系统 · 海马记忆】** 检索策略 → 文献池 → 引用跨库验证（DOI 指向核对）。
   器官 `ref-manager`（Jing）✅有
   - 细胞：`fetch`+条件{PubMed检索}、`llm`+条件{相关性筛选}
8. **【写作系统 · 语言皮层】** IMRAD 初稿，叙事整合（把数据/图/文献缝成一条故事线）。
   器官 `manuscript-draft`（Hao）✅有

### 反馈 → 免疫系统全程巡查（见 §3）
### 输出 → 运动神经
9. **【交付】** 投稿包打包 → 交付物落 Drive，邮件通知客户。
   器官 `submit-package` → `delivery`（Wei）✅有；`io·通信细胞`⚠️缺接入

## 3. 免疫系统：质检不是终点，是全程巡查（反馈回路）

智慧体的稳定来自反馈。免疫细胞**在每个器官出口设卡**，不合格就回流重做——这就是"质量前置(Shift-Left)"：

| 卡点 | 免疫细胞 | 拦截什么 | 现状 |
|------|---------|---------|------|
| 数据出口 | `data-forensics` | 伪造/逻辑矛盾/异常分布 | ✅ |
| 分析出口 | 前提检验 + `devil` 红队 | 方法误用、过度推断、p-hacking | ✅ |
| 图表出口 | 数字对账 | 图文不一致 | ✅ |
| 文献出口 | DOI 跨库核对 | 引用幻觉/指向勘误版 | ✅ |
| 终审 | `quality-review` 八层 + Alex 一票否决 | 学术诚信红线 | ✅ |

> 缺的不是免疫细胞，是**让它们自动挂在每个器官出口**的神经接线——又回到 §2 第 2 步那根缺失的神经。

## 4. 可塑性：这一单结束后，身体长出新结构

交付完成触发 AAR（`evolution.md` L1）。假设本单发现："HFpEF 队列里 NT-proBNP 反复需要对数转换"——

并自动挂进数据系统器官。下一单同类数据直接复用。**经验沉淀 = 谱系上的结构生长**，可追溯、可回滚。

## 5. 这个场景暴露的缺口清单（= P1 要建的东西）

跑这一条反射弧，缺的全部集中在**神经系统**，器官基本都在：

1. ⚠️ **编排细胞 / 控制流**（§2-2）：能接住任务、按契约把它在器官间路由。**最高优先。**
2. ⚠️ **能力发现 + 谱系注册的运行时**（让任意 Capability 注册即可被编排）。
3. ⚠️ **免疫接线**（§3）：质检细胞自动挂到器官出口。
4. ⚠️ **IO 细胞接入**（§2-1/9）：Gmail/Drive 收件与交付。
5. ⚠️ **统计器官的真实化**：把 `stat-analysis` 从 SKILL.md（手写 SOP）落成 kernel 里 `compose` 的真器官（Cox/KM 细胞）。
