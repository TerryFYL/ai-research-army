## 一、总纲（一句话）

> 从裸的大模型 API 出发，自底向上，用**分化**和**组合**两个最小算子、照**人体**的组织方式，
> 长出一套能**自我建造**、并最终完成**各种各样复杂任务**的能力体系。
> 复杂能力不是被设计出来的，而是当**连通的能力跨过临界质量后相变涌现**的。
> 整个建造过程由一个**朴素的科学循环**（可测目标 → 假设 → 最小实验 → 数据验证 → 决策）自动驱动。

---

## 二、探索方向

1. **自底向上，从原子长起。** 不从复杂任务往下拆，而从最基础的能力往上搭。
2. **两个算子 + 一个统一类型。**
   - **分化** `differentiate(base, +条件)`：一生多（纵向特化，干细胞加条件派生专门细胞）。
   - **组合** `compose(members, wiring)`：多合一（横向聚合，专门细胞拼成器官/系统）。
   - 干细胞、专门细胞、器官**都是同一个类型 `Capability`**，因而能递归自相似地向上生长。
3. **照人体蓝图建。** 细胞 → 器官 → 系统 → 个体；并建横切子系统：
   神经（编排）/ 免疫（质检）/ 内分泌（全局策略）/ 循环（供给）/ 可塑性（进化）。
   **大模型本身是一颗预训练好的"超级细胞/皮层"**，我们要建的是把它接进去的"身体脚手架"，不是大脑。
4. **关键洞见：通用性是涌现的、是"量"的相变。** 当"分化/组合"成为神经系统的*运行时操作*、
   且连通的细胞跨过临界质量，复杂任务**突然**变得可达。量不够、没连通，就是做不起来。
5. **资源不设限。** 凡当前能拿到的（云、付费 API、各类 MCP 集成）都是基建——缺一个接一个，不是根本限制。

## 三、最终预期目标

- **根本目标（体系）：** 一套能完成各种各样复杂任务、且能自我生长的能力体系。**体系先于任务。**
- **落地北极星（可测）：** M2 —— 用曙光心衰数据**全自动**跑通「数据 → 统计分析 → 投稿级初稿」，无人工断点。
  它不是"要完成的那个任务"，而是这具神经系统长成时**顺手就能装配出的第一条复杂通路**。
- **"投稿基础稿"的完成定义（definition of done）：** 流程跑完 ≠ 任务完成。"投稿基础稿"必须有
  **清晰、可验证的标准**，否则即使流程完成也满是问题。标准 = f(目标期刊, 研究类型)，从四层权威源头
  （期刊作者须知 / EQUATOR 报告规范如 STROBE / ICMJE 诚信 / 顶刊写作指南）编成一份**审核清单**，分两层判定：
  **合格**（所有硬闸门全过，等价于"不会被 desk-reject"）＋ **高质量**（质量评分 ≥ 阈值）。
  这份审核清单就是科学循环第 4 步的**客观验证器**。详见 `manuscript-standard-methodology.md`。
- **目标的度量方式：** 不用"完成了几个任务"衡量，而用**可达任务空间有多大 / 复杂目标点亮没 /
  离下一次相变还差哪几个连接子**衡量。质量则用**审核清单的硬闸门通过率 + 质量评分**衡量。

## 四、方法论：朴素的科学循环

整个建造由一个自动循环驱动。它本质是**科学方法跑成闭环**，朴素到只有五步，
科学性来自**纪律**而非复杂度。

```
0. 一次性：把目标定义成可测的设定点（指标 + "够了"的阈值）
循环：
  1. 观察 —— 量当前状态 vs 设定点 = 差距
  2. 假设 —— 写下最小的、可证伪的下一步 + 预设的成功判据
  3. 实验 —— 跑这个最小实验
  4. 分析 —— 数据是否达到预设判据？（主动找反例，不是找支持）
  5. 决策 —— 达到→提交（差距缩小）；没达到→丢弃、记账、换假设
直到 差距 ≈ 0
```

**三道纪律（朴素版与科学版的分界）：**
1. **目标可测**：先把目标翻译成一个能量出来的数。没有它，循环没有梯度也没有停止条件。
2. **判据先写死 + 主动证伪（Popper）**：实验前定死成败标准，并主动试图推翻它。专治"乐观幻觉"。
3. **最小实验 + 知识账本**：一次只动一个变量（可控、能归因）；每圈记"假设→结果"，
   让循环不重复死路、越跑越聪明（即"选信息量最大的下一个实验"）。

**一条红线：** 第 4 步验证必须**客观、从数据里量出来**，禁止大模型"自己判自己作业"——
否则循环会收敛到"看起来完成"，而非"真的完成"。（这正是医学零容错红线用在循环自身。）

**战略原则（让临界点够得着）：** 沿目标任务的**依赖闭包定向生长**细胞、优先补**连接子**、
**广度与可靠度同步**长大——用契约把相变的临界点拉到人力可负担的规模，不靠"大力出奇迹"。

## 五、执行准则

1. **体系先于任务。** 建"会自己长出解法的体系"，不是一条条手写流水线。
2. **自举。** 这个科学循环自身是第一个细胞，它的**头一份工作就是建造其余部分**。
3. **越简单越朴素越好。** 力量来自纪律，不来自复杂度。能砍的复杂度都砍掉。
4. **可追溯、可回滚。** 每一步进化都记录、都能撤销（对接 `evolution.md` 红线）。
5. **医学零容错。** 统计真算、引文跨库验证、方法存疑选保守。
6. **用仪表盘看进度。** 盯"可达任务空间 / 复杂目标点亮 / 离下次相变的距离"，而非任务计数。
