# Supplementary File 2. Reproducibility Note

This submission package includes the following reproducibility materials used for the current draft:

- `manuscript.md` and `manuscript.docx`: current manuscript source and editable document.
- `table1.md` to `table4.md`: manuscript tables reporting descriptive characteristics, primary models, subgroup estimates, and sensitivity analyses.
- `make_figures.py`: figure-generation script used to render the submission figures included in this package.
- `strobe_checklist.md`: completed STROBE checklist referenced in the Methods section.

Additional project records retained in the working directory include:

- `analysis_results.md`: analysis summary used to derive the reported model estimates.
- `data_cleaning.md`: cohort construction and cleaning log.
- `variable_construction.md`: exposure and covariate derivation notes.

The full R analysis scripts underlying the survey-weighted models are not yet in a public repository. They will be provided to editors and reviewers on request during peer review and deposited in a public archive after acceptance.
